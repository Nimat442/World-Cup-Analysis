# World-Cup-Analysis

##  Overview

An interactive data analysis project exploring FIFA World Cup participation, attendance, qualification, hosting, winners, and competition trends.

##  Objectives

- Analyze World Cup attendance by country and year
- Explore countries that qualified for the tournament
- Analyze World Cup winners and host countries
- Examine competition statistics across different years
- Present historical trends through interactive visualizations

##  Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Dashboard Development

##  Analysis

The dashboard explores:

- Attendance by country and year
- World Cup results
- Competition statistics
- Countries qualified
- World Cup winners
- Countries that hosted the tournament

Data Analysis • Power BI • DAX • Data Visualization • Dashboard Development • Trend Analysis • Sports Analytics
